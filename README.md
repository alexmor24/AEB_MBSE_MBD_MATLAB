# Automatic Emergency Braking (AEB) – MBSE & MBD Project

## Overview
This project demonstrates the development of an Automatic Emergency Braking (AEB) system using:
- Model-Based Systems Engineering (MBSE)
- Model-Based Design (MBD)
- MATLAB / Simulink toolchain

The goal is to show a complete workflow from stakeholder needs and system requirements to functional architecture, control modeling, and requirements verification through simulation.

## Scope
- Longitudinal AEB only
- Single lead vehicle
- Straight-line driving
- Abstracted perception (no raw sensor modeling)

## Tools
- MATLAB
- Simulink
- Stateflow
- System Composer
- Requirements Toolbox
